# iclip-agent 领域锚点

本文是 Productor 视频创作产品的领域锚点：上下文（产品与系统的背景事实）、术语（产品赖以工作的持久事实与瞬态信号）、不变量（每条代码路径都必须成立的规则）、禁止逻辑（被刻意设计掉的推理模式）。

本文只登记已落地的领域真理——术语与不变量随实现进入本文，未实现的部分不进本文。命令与门禁见 [../AGENTS.md](../AGENTS.md)；机制见 [architecture.md](architecture.md)；技术方案的选择与权衡见 [adr/](adr/)。

## 上下文

- **产品**：Productor 是 AI 视频创作产品。用户与 AI agent 对话推进创作：从参考素材拆解，到镜头 prompt 表，再到镜头帧与媒体生成。
- **系统**：`web/`（React SPA，同源 `/api` 直连后端）+ `server/`（FastAPI 模块化单体）+ Postgres（唯一事实源）。外部依赖：企业 SSO 与 PMS（企业身份与部门资料）、LLM 引擎（PydanticAI）。
- **`web/` 的角色**：产品前端。它只消费合同，不定义产品行为：端点形状从 [../contract/openapi.json](../contract/openapi.json) 生成，合同表达不了的约定在 [../contract/conventions.md](../contract/conventions.md)。前端自己的命令、边界与门禁见 [../web/AGENTS.md](../web/AGENTS.md)；本文的术语与不变量两端共用。

## 术语

**主体（Principal）**：
一次请求的唯一可信身份：`kind ∈ {user, api_key}`、`user_id`（key 也归属用户）、`api_key_id?`、生效权限集。由宿主的 PrincipalResolver 每 hop 解析一次，下游一切只消费它。
_不是_：客户端提交的任何身份字段、可在下游二次解码的 token、两套并行的用户/机器身份模型。

**API Key**：
`iclip_sk_` 前缀的长期凭证，归属某个用户；服务端只存 SHA-256 哈希与展示前缀，明文仅创建响应出现一次。key 的有效权限就是**显式授予集**（签发时校验 ⊆ 签发者当下权限；签发权 `api_keys:issue` 仅 root 角色持有）。
_不是_：角色的镜像、独立账号体系、可查回明文的凭证。

**角色（Role）**：
权限集合的命名快捷方式，代码内预置（root/editor/viewer），无角色管理表。用户有效权限 = 所分配角色的权限并集 ∪ 直接授权。
_不是_：身份等级体系、可动态定义的实体、第二套授权机制。

**双主体（Dual Principal）**：
同一套产品能力对两类调用方开放：浏览器用户（HttpOnly cookie `iclip_session`）与机器调用方（`Authorization: Bearer iclip_sk_...`）。两者解析为同一 Principal 类型，权限词汇表相同。
_不是_：两套 API、两套权限系统、为机器单开的旁路。

**运行目标（Run Target）**：
承载一个 agent 运行的顶层 Agent，由声明式配置定义（官方 spec × prompt 资产 × 能力声明 × 下属声明），启动期装配冻结、运行期按 id 读取。id 是唯一权威身份：它同时是 URL 里的 `{agent_id}`，并被强制覆盖成 agent 的 `name`。
_不是_：模型配置本身、客户端可指定的东西、可在运行期改写的选择。

**对话（Conversation）**：
用户界面上的一个聊天窗口，也是需求单下的一次尝试：有属主、有名字，可改名、可删除。id 由服务端发放，发消息、读 transcript、订阅都按它走；一段对话下有多次运行，运行按对话归档，agent 工作区按对话隔离。删除对话时一并删除其工作区文件，运行记录保留。
它带两处归属，各自独立、都可为空、都可随时更换：所属需求单（至多一张），所属合集（至多一个）。同一需求单下可有多段对话，按创建时刻排序。
只有属主看得见自己的对话；持 `users:manage` 的治理者读得到全部（对话历史、工作区文件与审计列表），用于复盘创作质量——只读，写入路径仍限属主。
它此刻**在忙什么**是三件互不蕴含的事实：有轮次正在跑（busy），有没有卡在等人点头（approval / question，两者都有时审批优先），以及最近一轮的结局（completed / failed / aborted）。**等审批的时候仍然是 busy**——那一轮并没有结束，所以这些事不能合成一个状态枚举。
_不是_：客户端自行编造即可成立的 id（发消息时服务端核对，对不上按不存在处理）、cookie 会话、消息历史的容器、需求单的一部分（需求单删除后对话保留，只是不再指向任何单）、一个「状态」枚举（在跑与等人是两件事）。

**合集（Collection）**：
对话的分组单位，有属主：持 `collections:read` 只看得见自己的，别人的一律不存在；治理者可列出全部（只有元信息，内容仍按对话那一条）。改名与删除限属主或治理者，需 `collections:write`。
_不是_：需求单的分组单位（单与合集之间没有关系，需求单直接对应对话）、权限边界（对话的可见性只看对话属主，与所在合集无关）、内容物的容器（删除合集不删除对话，只把对话上那一列置空）、agent 工作区（那是一段对话里 agent 写下的文件）。

**Agent 运行（Agent Run）**：
一次 agent 执行的持久事实：血缘（自身、所属对话、父运行）、逐步事件、可续跑的消息历史快照、工具副作用状态，全部落 Postgres。续跑与恢复靠读库。
_不是_：进程内存里的会话对象、worker 内存缓冲、可由客户端提交或改写的数据。

**运行依赖（Run Deps）**：
一次运行携带的可信身份，就是发起它的那个主体。运行发起时捕获一次并随运行冻结（跑到一半吊销不中断它），下属运行自动继承同一个。工具的授权与审计只认它。
_不是_：装配期挂在 agent 上的东西、服务与连接的容器（那些由组合根在装配期注入）、客户端可写入的对象（客户端提交的 state 一律不消费）。

**对话素材（Conversation Material）**：
模型能交给工具的地址：这次运行的模型请求一侧（用户消息、工具结果、agent 指令）逐字出现过的媒体地址。用户附件带 tag，种类明确；工具产出的地址不带种类，只确定来自本对话。下载整片或付费出图的工具要求地址出现过且声明过匹配的种类。
_不是_：一张登记表或库表（判据是消息列表本身）、安全边界（防 SSRF 在出网取素材那一层单独做）、模型自己写下的地址（响应侧一律不算）。

**Transcript**：
一段对话给人看的那份记录，形状按 kimi code 协议：轮（一条用户消息引发的全部运行）→ 步（一次模型响应）→ 块（正文、
思考、工具卡）。它是**投影不是事实源**——已经跑完的轮子从消息历史现推，正在跑的那一轮在进程内存
里，客户端断线后按批次号补批。轮、步、块的编号一律从消息里确定的事实算出来，不按事件到达次序，
所以同一段对话在刷新前后不会变形。
_不是_：事实源（持久事实只在 Postgres）、消息历史（那是快照）、绑在某次 HTTP 请求上的响应体、可跨用户寻址的东西。

**生成任务（Generation Job）**：
一次媒体生成的持久事实：发起者（含哪把 key）、请求参数（有类型，含用哪个模型 / 走哪个渠道）、当前状态、结果。表中只有事实；排期（执行时间、重试次数、执行者）在任务队列自己的表里。受理时不调用外部接口；推进由后台完成，与 HTTP 请求无关。
_不是_：内存里的待办项、绑在某次请求上的同步调用、外部接口状态的镜像（provider 的状态字符串原样存着，不映射成自己的枚举）。

**生成结果（Generation Output）**：
一次成功生成对外给出的那个地址。图片结果转存成本系统的公开对象后才算数（provider 给的是会过期的签名 URL）；视频结果为 provider 的地址。
_不是_：会过期的签名链接（图片）、provider 原始响应（那是排障快照，不对外）。

**产品资料（Product）**：
一个款在 PDM 里的资料快照：款号、状态、品牌、品类、颜色和产品图。数据在外部只读库（PDM 经 CDC 同步的副本），按款号读取，不落库、不缓存、不改写。上游只给编码（品牌 `"2"`、品类 `52`），对照表在本仓代码里；查不到的编码 name 为 null。款另有 WMS 编号，与 PDM 款号不通用。
_不是_：本系统的实体（没有产品表）、可写的东西、素材登记表里的条目（图片地址仅供展示，进登记表须另行转存）。

**素材（Asset）**：
登记表中的一行：本系统自己存储的一份媒体——公开桶里的 object key、类型、大小、上传者。行上不存地址，地址由 key 与当前公网前缀拼出。进登记表的前提是字节已转存进本系统的桶，外部地址不能登记。上传分两步：先申请对象名与限时直传地址（不落库），浏览器直传后再登记；登记时的事实全部从桶里读取，不采用客户端上报值。素材全公司共用，上传者只是查询维度，不是访问边界。
_不是_：对话素材那道校验（判据是对话中是否逐字出现过；登记过不等于模型可用）、生成任务、外部地址的登记处。

**创作需求单（Task）**：
一份记录在案的视频创作要求：创建者、内容、期限、状态、认领人集合。没有属主，持有 `tasks:read` 即可见全部。草稿阶段只有创建者与治理者可改可删；下发后需求方填写的创作输入冻结，可改的只剩管理信息与接单后补充的项（时长、画幅、需求描述、参考素材）。认领与撤回任何有写权限的人都可做：认领把认领人记进 `task_assignees`（一张单可多人认领，同一人只记一行），撤回是终态，认领记录不随撤回抹掉。
_不是_：私人资源（不做归属过滤，可见但不可改返回 403）、生成任务、可删除的历史（下发后只能撤回）。

**爆款视频（Inspiration Video）**：
自家款在平台上的短视频及其表现指标、CT 归属与平台类目。数据在外部只读库（数仓爆款榜），按款查询，不落库。查询用 WMS 编号，不是 PDM 款号。排序与截断在库里完成。
_不是_：本系统的实体、素材登记表里的条目（视频地址仅供展示，进登记表须另行转存）、可由综合分排序的东西（排序维度由调用方指定）。

## 不变量

每条代码路径都必须成立。破坏任何一条都是设计变更，须显式决策。

1. **Postgres 是唯一持久化事实源。** 业务事实、agent 运行与消息历史都落 Postgres；worker 进程内存只承载当前连接、当前 run 或性能缓存，不承载跨 worker 正确性。正在跑的那一轮的 transcript 只在进程内存里，可整段丢弃而不损失事实（跑完的轮子从消息历史现推），不构成第二个事实源。
2. **可信身份只来自宿主建立的唯一 `Principal`。** PrincipalResolver 每 hop 只解析一次（cookie 验签一次 / key 哈希查表一次 + 活跃属主加载一次），写入 `request.state.principal`；下游不得再解码 token、查询用户或消费客户端身份字段。Principal 解析与传输无关：HTTP 中间件、WS 握手（cookie + Origin 校验）与 Bearer 头共用同一解析器。
3. **权限集合是唯一授权货币。** 用户有效权限 = 角色权限并集 ∪ 直接授权；API key 有效权限 = key 显式授权集。签发需 `api_keys:issue`（仅 root），签发时校验授予集 ⊆ 签发者当下权限；过期、吊销或属主停用的 key 一律 401。
4. **key 行为可审计。** 所有事实行记录 `user_id + api_key_id?`——谁的 key 干的，永远可追。
5. **地址与密钥只存在于环境变量。** 配置 YAML 只有形状，地址与凭证不进仓。运行必需的变量在 bootstrap 阶段一次全报出来（报变量名）；空串与空白等于没设；API key 只存哈希。
6. **run 生命周期由数据库持有。** 没有自定义 pending 运行时、没有本地 run 队列；运行事实先落库，恢复与续跑一律读库。运行也不由某次 HTTP 请求持有：客户端断开只结束订阅，不取消运行。
7. **运行目标只有一个声明事实源。** 配置声明 → 装配期冻结；路由、白名单、能力挂载都从它派生，不得各自重建平行映射。
8. **客户端生成的 id 只做幂等键，服务端发放的 id 才做身份。** 运行 id 由客户端在发起之前生成；会话 id 由服务端发放。
9. **行级归属语义**：不可见资源返回 `NotFound`（不泄露存在性），可见但禁止才是 `PermissionDenied`；manager 视角不加 owner 过滤。
10. **付费的外部调用不自动重投、也不替调用方换参数。** 视频与图片生成接口没有幂等键。调用前先落「正在提交」；任务重跑时先重读该行，仍为「正在提交」的判失败并写明原因，写入带状态守卫。用哪个模型、走哪个渠道由请求指定。失败照实记录，附上足以判断「送到了没有」的错误码。所有时刻取数据库时钟。
11. **进模型上下文的媒体必须配一条 tag，工具产出的地址必须进入上下文。** 往上下文放媒体（用户附件、工具附回的图）时，同一位置放一条 `<kind url="…">`。工具产出的地址必须经返回值或工作区文件之一进入上下文。

## 禁止逻辑

被刻意设计掉的推理模式，不得以「临时方案」名义重新引入：

- **信任客户端身份。** 任何来自 body / query / header（除凭证本身）的 userId、tenantId、role 都不得进入可信路径；run 按服务端事实定位，不按客户端提交的 id。
- **把 key 当角色用。** 不得给 key 授予「随属主角色自动膨胀」的权限；扩权只能重新显式授予。
- **伪造终态。** 运行事实不完整时只允许显式可重试错误，或以已落库事实收尾；不为没有终态记录的 run 合成成功终态。轮的终态同理：只认官方记下的那条 run 结束事件，没有记录就是没跑完，不按消息形状猜一个出来。
- **无声接不上。** 客户端带位置续读而该位置之前的事件已过重放窗口时，明确拒绝并要求重新发起；不跳到当前位置。
- **静默兜底。** 配置 env 缺失、持久化状态形状非法、协议边界损坏，都在最早的边界报错，不降级运行。
- **让模型自己认领素材。** 工具收到的地址按「模型请求一侧是否出现过」判定；模型正文、工具调用参数、厂商内建工具带回的地址都不构成素材。校验失败的报错不回显被拒地址。
