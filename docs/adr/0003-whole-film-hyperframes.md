# ADR-0003：基于 HyperFrames 重构成片编辑器与服务端渲染导出

- **状态**：已接受（2026-10-17）
- **影响范围**：[CONTEXT.md](../CONTEXT.md)（成片草稿、导出、生成任务、资料库、埋点事件）；[contract/openapi.json](../../contract/openapi.json)；[contract/conventions.md](../../contract/conventions.md) §6；[architecture.md](../architecture.md)；[deploy.md](../deploy.md)

## 背景

早期的成片功能在前端浏览器里用 DOM 预览、在后端用 ffmpeg 命令拼接导出，字幕排版和混音逻辑在两端各写了一套，即使靠测试金样对齐也依然存在视觉与时间差。

开源的 HyperFrames（Apache-2.0 协议）支持用**同一份 HTML 合成页面**既在浏览器中实时播放预览，又在服务端无头 Chrome 中逐帧渲染导出 MP4，同时自带成熟的时间线剪辑计算、动态组件机制与音乐节拍分析能力；配合千问语音识别返回的逐词时间戳，可以实现预览与导出 100% 一致的成片效果。

## 决策

1. **预览与导出共用同一份合成代码**：前端浏览器预览与后端渲染导出共用同一套 TypeScript 合成代码（`composition/`），将成片草稿转化为标准 HyperFrames 合成页面。导出由独立的 Node 渲染服务（`render/`，基于 `@hyperframes/producer` + 无头 Chrome + GPU）执行，不再自行编写底层字幕排版或音频限幅逻辑。
2. **精简引入 HyperFrames 依赖与外置组件库**：
   - 安装 `@hyperframes/sdk` 用于画布点击命中检测与边界计算；对于 `@hyperframes/studio`，不安装整个 UI 包，只将其时间线拖拽、修剪、吸附与叠放纯算法源码摘录到本仓库 `vendor/hyperframes-studio/` 下，编辑器界面由我们自己实现。
   - 动态组件库（含 `catalog.json`、组件代码与字体文件）独立于应用镜像维护，在部署目录只读挂载给前端与渲染服务；新增或修改组件只需更新挂载目录，无需重新发版。
3. **成片草稿保存在服务端**：每段对话维护一份成片草稿（采用版本号乐观锁整份覆盖，不保留历史版本）。画面轨强制要求从 0 起首尾相接（每次编辑后自动收紧空隙，字幕跟随所属视频段平移，背景音乐与特效轨位置保持独立）。
4. **异步渲染导出与下载归因**：每次点击导出都会创建一条 `kind: "whole_film", operation: "render"` 生成任务，交由渲染服务单任务排队渲染并上传为永久公开的 OSS 对象，同时收录进资料库的「成片」页签。渲染服务重启或用户手动取消均将任务记为失败。下载成片记一条 `video.downloaded` 事件，`jobId` 是这条成片记录；成片用到的素材片在读取时按血缘归因。
5. **编辑器工作台布局**：页面上方为四轨成片时间线（画面、特效、字幕、音乐），下方为按原作分组的视频素材区；左侧栏提供「素材（音乐）」「品牌组件」「通用组件」三个面板，支持在预览画布上直接点选、拖拽、缩放、旋转特效与字幕，以及双击直接改字。
6. **逐词字幕与自动卡点**：使用千问 ASR（`qwen-audio-3.1-asr-flash`）识别并保存每句话的逐词时间戳（用户手动改过字的句子按字数均分原句时长）。前端使用 `@hyperframes/core/beats` 分析背景音乐节拍，「自动卡点」功能将视频切点对齐到最近的音乐拍点（若会截断人声口播或素材长度不足则保持原位）。
7. **统一组件与字体机制**：组件放在画面轨上即作为占时长的独立视频段（如片头片尾），放在特效轨上即作为叠加图层（含转场）。组件与字幕支持通过外部容器的 `--font-display` / `--font-body` CSS 变量切换品牌字体（中文自动回退至 Noto Sans SC）。

## 取舍

- **接受**：
  - 每次导出需要等待服务端逐帧渲染完成，且依赖带 GPU 的渲染容器；
  - 升级 HyperFrames 引擎或组件库后，旧草稿重新导出的视觉细节可能随之更新；
  - 不同视频片段之间不做自动响度均衡或切点交叉淡入淡出；
  - 人工修改过文字的字幕句子，其逐词高亮时间为按字数估算值。
- **不做**：
  - 不保存成片草稿的历史版本；
  - 不在用户浏览器端本地渲染导出视频；
  - 不直接安装 `@hyperframes/studio` UI 组件包，也不设置独立的右侧属性栏。
