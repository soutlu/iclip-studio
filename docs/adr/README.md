# 架构决策记录（ADR）

本目录存放已接受的架构决策。新增或修改 ADR 时遵守下列规则；普通文档与代码注释怎样引用 ADR 见 [AGENTS.md](../../AGENTS.md#4-文档维护)。

- 位置与编号：ADR 放在 [docs/adr/](./)，文件名 `NNNN-slug.md`，编号从 0001 顺排；前后端共用这一个目录。
- 门槛：只记开发者逐点拍板过、并且同时满足三条的决策——难以撤回、不交代背景后来的人会觉得意外、确实有别的方案被比较过。方案阶段的草稿不进仓库。
- 写法：标题 `# ADR-NNNN：<决策>`；开头几行写状态与日期、取代或沿用了什么、影响哪些文档；正文分「背景」「决策」「取舍」三节，取舍分「接受」与「不做」；只写决策与理由，不写实施进度。
- 怎么改：已接受的 ADR 不改决策；笔误、失效链接直接改正。决策变了另写一篇，新篇开头写「取代 ADR-NNNN 第 N 条」；旧篇只改状态，整篇被取代写「已被 ADR-NNNN 取代」，部分被取代加一行「修订（日期，ADR-NNNN）」。
