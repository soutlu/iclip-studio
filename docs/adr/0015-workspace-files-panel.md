# ADR-0015: 右侧面板加「文件」——整个工作区是一件产物，收起态是一张菜单

- 状态：已接受（2026-09-05）
- 推翻 **[ADR-0009](0009-storyboard-workbench.md)** 取舍「不做通用文件浏览器」；沿用其决策 1 的宿主与注册表，产物来源从两种增为三种。
- 补充 **[ADR-0014](0014-subagent-panel.md)** 决策 2：宿主的切换器由菜单换成并排标签，派活卡只在被点开时占标签位。
- 合同 [contract/conventions.md](../../contract/conventions.md) 文件订阅一节：`watch_fs_add` 的路径给空串即工作区根。

## 背景

工作区里 agent 写下的文件（拆解文档、角色设定与拉片表、镜头组 prompt 表、取帧与出图记录、设定图记录）只有 `video_shot.json` 能在右侧面板看到，其余只能靠聊天里的工具卡回忆。文件存储是纯文本，每份几 KB，里面的图片与视频是地址。

宿主的文件列表只在断线重连时重拉：agent 第一次写出 `video_shot.json` 时，分镜标签不会实时出现。宿主折叠后是一个浮在内容上、带阴影的展开钮，两侧一样。

## 决策

### 1. 整个工作区是第三种产物来源

- `ArtifactSource` 加 `{ kind: "workspace" }`，注册表加匹配方式 `{ workspace: true }`：工作区里有文件就命中一件产物，id 为 `workspace`。渲染器自己读文件列表，来源上不再带一份。
- 注册表条目加 `label`（这一类产物的名字）、`icon`（菜单图标）、`empty`（常驻类型还没有产物时菜单里那一句说明）。按路径与按工作区命中的类型是**常驻类型**。
- 在 `app/` 登记 `features/workspace` 的渲染器，`autoOpen: false`。宿主仍不认识任何具体类型。

### 2. 收起态是一张菜单，展开态是并排标签

- 收起时右上角一个普通图标钮，点开列出能打开的产物：常驻类型一行一个（没有产物的灰着并带 `empty` 那句），工具卡产物一件一行。选哪个就展开并切到它。
- 展开时头部是标签栏：常驻类型的产物各占一个标签；工具卡产物只有被地址点名（点了派活卡的「查看」）时才占标签位，切走即退回菜单。
- **只有 autoOpen 的产物落地（分镜交付）或地址点名了某件产物，面板才自动展开**；其余时候等用户从菜单里点。用户的折叠选择照 ADR-0014 的口径，直到聊天里下一次「打开」请求为止。
- 两侧收起态的展开钮不再浮在内容上、不带阴影；壳把开合状态给页面，页头两端为它留位。没有声明面板的页面不再画空面板占位。

### 3. 文件页：列表与阅读，按后缀选渲染器

- 列表按目录分组，根目录在前；行上是类型图标、文件名、大小、更新时间。正在看的文件路径放会话路由查询串 `file`。
- 渲染器按后缀选，不认识任何具体文件名：Markdown 用聊天回复同一套排版；JSON 排成可折叠的树，值是图片地址的显示成缩略图并可放大，视频与其他地址是外链，另有「看原文」；其余按行显示。没有后缀的文件内容以 `{` 或 `[` 开头也按 JSON 试。解析失败明示错误并退回原文。
- 一份文件本身登记成了别的产物（如 `video_shot.json` 之于分镜）时，阅读头上给「在分镜里打开」。
- 只读。写接口已有，但在阅读器里改文件是另一个功能。

### 4. 刷新信号：宿主订整个工作区

- 服务端 `watch_fs_add` 的路径为空串时视为工作区根，`recursive` 为真收到整个工作区的变动。
- 宿主用它订一次：任何文件变了，文件列表与那个文件的查询一起失效。分镜标签在 `video_shot.json` 落地那一刻出现。分镜面板自己那条精确路径订阅随之删除，渲染器只认查询结果里的版本号。

### 5. Markdown 组件下沉

`AssistantMarkdown` 与 `CodeBlock` 连同排版样式挪到 `shared/ui/markdown`，聊天与文件页共用一份。

## 取舍

- **不做左右双栏。** 面板最窄 560，Markdown 里是三到五列的表格；列表与阅读两个画面来回切，阅读占满宽度。
- **不按每种 JSON 各画一套专用界面。** 通用树加缩略图已经能看清出图记录与设定图记录；将来某种文件值得专门画，就是再登记一条产物类型。
- **有文件不自动展开面板。** 第一份拆解文档落地时不抢聊天宽度；代价是用户要知道菜单里有「文件」。
- **不做快捷键。** 桌面端那种 ⌘P 一类的组合键在浏览器里与系统快捷键冲突多，等面板稳定再定。
- **接受工具卡产物在菜单里一件一行。** 派活多了列表会长；标签栏不受影响。
