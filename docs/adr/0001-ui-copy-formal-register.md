# ADR-0001：界面文字用书面语

- 状态：已接受（2026-10-09）
- 影响：[前端实现规范](../../web/docs/frontend-implementation.md#界面文字)「界面文字」一节引用本篇。

## 背景

界面文字口语化，同类提示写法不一。

## 决策

界面上的所有文字都遵守以下要求，包括按钮、标题、提示和前端产生的报错。后端接口返回的报错原文除外。

1. 用书面语，不用口语和语气词：写「无法」「尚未」「查看」「该 / 本 / 此」，不写「不能」「还没」「看」「这条 / 这张」。
2. 不称呼用户，不写「你」「你的」。
3. 按钮和标题写完整的动宾或名词短语，如「采用最新版本」，不写「用最新的」。
4. 提示按句式写：阻止「原因，无法 X；请 Y」，失败「X 失败，请 Y」，进行中「正在 X」，完成「已 X」，空状态「暂无 X」，引导「动作 + 可 + 结果」。
5. 报错不出现英文、字段路径和状态码；后端原文前只加一层「X 失败：」。
6. 单句提示不加句号；术语照 [CONTEXT.md](../CONTEXT.md)。

## 取舍

- 接受：语气偏正式。
- 不做：内部页面不放宽。
