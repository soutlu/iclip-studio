# ADR-0011：工程文件照 hypit 写成文字、模板与剧本，参考图挂在生成节点下，编号用时现算

- 状态：已接受（2026-10-07）
- 取代 ADR-0007 第 2 条（出场元素层与 `Cast`）、第 4 条（没有模板）；ADR-0007 的其余各条与 ADR-0009 不变。
- 影响：[CONTEXT.md](../CONTEXT.md) 的「工程文件」「制作页」词条、[architecture.md](../architecture.md) 的 `iclip_studio` 说明、[contract/conventions.md](../../contract/conventions.md) §6 的制作页；后端 [iclip_studio/film/](../../server/src/iclip/capabilities/iclip_studio/film/) 的包声明、模板包、剧本、拼提示词、检查与制作页；前端制作页的全局设定 [film-script.tsx](../../web/src/features/storyboard/film/film-script.tsx) 与改过的描述 [film-images.ts](../../web/src/features/storyboard/film/film-images.ts)。

## 背景

ADR-0007 第 1 条定下工程文件的写法照 hypit，第 2、4 条却另造了一层：人物、产品、场景各写一个 `Element`，声音写 `Voice`，提示词用 `Cast` 引用元素、每处只带一张图，图片和视频的拼法由 `Picture`、`Storyboard` 两个标签写死在代码里。hypit 的写法是文字、模板、剧本三样：文字是一段一段的值，提示词按模板把文字填进槽里拼，台词是一份剧本，参考图写在生成节点下面。照搬时只有一处真的不同：hypit 的图号由作者手写在提示词里，出视频前列的图都会先生成好；我们的图由用户决定生不生成，写文件时不知道最后有哪些图。

比较过的方案：沿用 `Element` 与 `Cast`；照 hypit 把图号手写进文字；缺图时拦住生成，或自动先生成缺的图；照 hypit 写，参考图挂在生成节点下，图号生成时现算。

## 决策

1. **出场元素、声音、拍法都是文字。** 每样写一段 `text:Value`，`id` 就是它的名字；声音的说话人写在正文开头。不再有 `Element`、`Voice`、`Cast` 与提示词的块。
2. **提示词按模板拼。** 模板包 `@iclip/film-kits` 用 `import source` 引入，现在有 `画面-v1`、`多镜头视频-v1` 两份；`text:Render` 选一份模板，用 `Set`、`Append` 把文字填进槽里。模板包放在后端，不让人自己写；各段怎么排、图号写在哪段文字后面，每份模板一套，写在代码里。改模板的槽或排法时出一份新模板，旧的留着。
3. **台词是一份剧本。** `<script>` 的正文按 hypit 剧本写法的一个子集读：一句一段，段名在镜头正文里写 `{段名}` 引用，说话人写在剧本里；一个文件一份，写在镜头之前。
4. **参考图挂在生成节点下，图号用时现算。** 一张图或一次视频要参考的图，在生成节点下一张一行：写 `for` 的是元素的图，指向那段文字，一个元素可以挂几张；不写 `for` 的正文写用途，只用在生图；视频的参考图都要写 `for`。镜头的机位图写在 `film:Shot` 的 `view` 上。图号不写进文件，每次生成时按当下有图的现算，写成 `@ImageN`；没图的不写图号，文字照写。
5. **`@iclip/director` 升 `@2`，只剩镜头。** 前缀 `film:`，只有 `Shots` 与 `Shot`。
6. **旧文件不兼容。** 按 `@iclip/director@1` 写的工程文件读到时报「没有这个包」，由 AI 导演按新写法重写。

## 取舍

- **接受**：人物的身材句只是一段追加在人物后面的文字，结构上认不出来；「人物要有身材句」「声音要对上说话人」这类规则不再由检查管，写进 AI 导演的写作指南。
- **接受**：图号的写法写在后端代码里，每份模板一套，加模板要改后端。
- **接受**：制作页全局设定里一个出场元素挂的图从一张变成一组，接口的 `image` 改成 `images`。
- **接受**：已经按旧写法写下的工程文件在制作页上显示有问题，要 AI 导演重写；运行文件里选用的节点名对不上的一起改。
- **不做**：沿用 `Element` 与 `Cast`。它与第 1 条的「写法照 hypit」不一致，一处 `Cast` 也只带得了一张图。
- **不做**：照 hypit 把图号手写进文字。写文件时不知道最后有哪些图，缺图时手写的编号会对不上发出去的图。
- **不做**：缺图时拦住生成，或自动先生成缺的图。生不生成、花不花钱由用户定；缺图时只用文字，图有了以后再生成，图号自动带上，两个文件都不用改。
- **不做**：兼容旧写法。film 运行时没进过发布版本，与 ADR-0009 第 3 条同一个理由。
- **不做**：让人自己写模板。模板里图号的写法在代码里；要开放时再把这套写法搬进模板文件。
