# ADR-0004：整片提供简化调音，自动处理保留用户的音量选择

- 状态：已接受（2026-10-15）
- 取代 [ADR-0003](0003-whole-film-editor.md) 第 5 条及「界面上不能调声音」的取舍；其余决策沿用。
- 影响：[CONTEXT.md](../CONTEXT.md)「生成任务」「生成结果」词条与[跨端合同「整片」](../../contract/conventions.md#整片)。

## 背景

自动等响和口播避让不能替用户决定每段原声与配乐的强弱。用户需要直接调节并试听，但整片页不承担专业多轨混音工作台的职责。音量关键帧、多轨编辑与独听等完整调音面板会增加这一流程的操作负担。

## 决策

1. 界面提供当前选中段的原声音量、整首配乐音量与紧凑的「自动对齐」按钮。原声仍与视频段绑定；静音由音量归零完成，不拆分人声与背景。
2. 系统继续负责原声与音乐的响度基准、切段淡变、按识别口播生成音乐曲线、音乐结尾淡出与最终限幅。用户音量在自动基准上生效；最终响度增益根据未调音的参考混音确定，不把用户调低的声音重新抬回。
3. 音乐自动对齐搜索能够匹配视频切点的起点，手动拖动不强制吸附拍点。视频切点不随音乐移动，单首音乐仍连续覆盖正文，不循环补长。
4. 用户音量与音乐起点进入草稿、撤销重做与合成请求；恢复成片版本时读回音量和音乐曲线。预览和导出消费同一份声音设置。

## 取舍

- 接受：提供逐段原声与整体配乐调节，用户不直接编辑自动曲线；原声包含素材已有的全部声音，单一音量不能分别改善人声与背景的比例；未识别到的口播无法自动避让，需要明确提示。
- 不做：音量关键帧界面、多首音乐拼接、独立音效轨、音画分离剪辑、AI 人声分离或服务端草稿。
