# ADR-0014：视频提示词里有图的出场元素只指向参考图，模板在原文件上改

- 状态：已接受（2026-10-07）
- 取代 ADR-0011 第 2 条末句「改模板的槽或排法时出一份新模板，旧的留着」；ADR-0011 的其余各条不变。
- 影响：后端模板包 [kits/](../../server/src/iclip/capabilities/iclip_studio/film/kits/) 里的 `多镜头视频-v1`、读模板的 [kits.py](../../server/src/iclip/capabilities/iclip_studio/film/kits.py)、拼提示词的 [prompts.py](../../server/src/iclip/capabilities/iclip_studio/film/prompts.py) 的 `render_video`。[CONTEXT.md](../CONTEXT.md)、[architecture.md](../architecture.md)、[contract/conventions.md](../../contract/conventions.md)、制作页、AI 导演的写作指南与前端不变。

## 背景

视频提示词的全局设定里，人物、产品、场景每项一行。原来不论有没有参考图，这一行都写这个元素的全部外观文字，有图时再在行尾接「参考@ImageN」，于是同一个样子用文字和图各说了一遍。测试规格里的示例片只有三个元素，全局设定 471 个字里这三行就占 276 个字。视频模型是 Seedance 2.5，火山方舟的[《Doubao Seedance 2.5 提示词指南》](https://www.volcengine.com/docs/82379/2607689)建议：参考图已经能准确表达的内容，提示词里只指向这张图，少重复描述；它的多角色示例只把名字和图对上，不写外观。

比较过的方案：照旧写全文字；让 AI 导演给每个元素另写一句简短描述；出一份 `多镜头视频-v2`，`v1` 留着。

## 决策

1. **视频里有图的元素只指向图。** 一个人物、产品或场景当下至少有一张图时，它那一行写成「槽 名字：几个固定的字参考@ImageN」，几张用「、」连起来，不加句号。人物写「长相、发型和穿着」，产品写「外观」，场景写「环境」，例如「产品 网面跑鞋：外观参考@Image2、@Image3」。这几个字写在模板文件对应的槽上，不写在代码里。还没有图的元素照旧写全文字。生图提示词、拍摄与剪辑、声音、镜头都不变。
2. **模板在原文件上改，不出新版本。** 改模板的槽或拼法时直接改那份模板；工程文件里写的模板名不变，下次生成时按现在的写法拼。

## 取舍

- **接受**：有图时视频模型拿不到元素的文字，文字和选用的图对不上时以图为准；图里看不出的小细节只能靠这张图和镜头的机位图带过去。这一改动没有在本产品自己的片子上比较过效果，依据是官方指南。
- **接受**：已有的工程文件从下一次生成起提示词变短；已经存下的生成记录保留当时发出的提示词。
- **不做**：让 AI 导演给每个元素另写一句简短描述。要改写作指南，写出来的描述又可能和图对不上。
- **不做**：出 `多镜头视频-v2`、留着 `v1`。已有的工程文件也该用上新写法，留着旧的只多一套要维护的拼法。
