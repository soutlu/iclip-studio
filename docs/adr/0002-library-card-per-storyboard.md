# ADR-0002：资料库一张卡是一段对话的分镜，副本按继承范围装卡

- 状态：已接受（2026-09-25）
- 取代 [ADR-0001](0001-video-domain-model.md) 第 3 条里「版本组是原作的（对话，`shot_index`）；原作没有 `shot_index` 时自己一组」与「在副本里剪继承来的出片，合成那行属于副本，版本归源那一组」，以及第 10 条「资料库：一组一张卡，卡面是最新一版」。沿用 #466 的继承规则本身（副本读得到祖先在分叉前完成的记录，不拥有它们）。
- 影响：[CONTEXT.md](../CONTEXT.md) 术语「镜头组」「生成任务」「继承」「资料库」；合同 [§11 媒体生成](../../contract/conventions.md#11-媒体生成-generations)（合成不再说成「同一原作下的新一版」，版本改按镜头组排）、[§13 资料库](../../contract/conventions.md#13-资料库-library)；[openapi.json](../../contract/openapi.json) 的 `/library/*`。

## 背景

ADR-0001 §3 把版本组定在原作的（对话，镜号），资料库一张卡是一镜。副本 B 在继承来的出片 X（对话 A 的镜头组 1）上剪出合成 Y，Y 归 A 那一组：A 的镜头组 1 与资料库卡面会因 B 的操作而变，A 的属主没做过这件事。开发者判断：Y 归 X 的血缘没问题，归 A 不对。

曾比较过「版本组按行自己的对话，继承来的行标『继承』、不占版本号，`GenerationOut` 加 `conversationId` 以便认出继承行」。它要给继承行贴标签，副本里的版本号与分镜页不连续，记录返回形状还要加字段。

分镜是创作的单位（ADR-0001 §2）：一段对话当前的出片方案，由镜头组按顺序组成，版本本来就是分镜里某个镜头组内部的事。资料库一张卡一镜，只是读模型当初的建法，不是领域上的必然。

现状代码里，分镜页按对话拿到的列表已经是「自己的行 + 继承来的行」，只按镜号分组；资料库 SQL 按 `root_job_id` 全表把合成挂到出片上，是唯一跨对话的地方。继承规则的判定在生成模块（SQL 与 Python 各一份），祖先链在对话仓储的递归 CTE 里；资料库按模块边界只能直接查表。

## 决策

1. **一张卡是一段对话的分镜。** 卡内按镜号分镜头组，组内成片按 `finished_at` 编 V1、V2……；没有镜号的出片各自一组，同原作的合成跟着它；不挂对话的出片一条一张卡，同原作的合成也跟着它。每一版的脚本与参数取它对应的出片：出片是自己，合成沿原作取，原作可以在祖先对话里。
2. **卡的内容是这段对话按「继承」规则读得到的全部成片**：自己的加继承来的，与分镜页同一集合，资料库不另定规则。合成只在这个集合内挂到出片上，不按原作号跨对话挂。继承来的成片不标注、不单列，每条成片各带自己的作者。
3. **自己至少一条成片才有卡**；在继承来的出片上剪出的合成算自己的。卡面是自己最新的成片。继承来的行完成时刻都不晚于副本建立时刻，自己的行都在那之后建立，所以自己最新的就是整卡最新的：有没有卡、卡面、排序、筛选都只看自己的行，血缘只在装填卡内容与详情时用。
4. **资料库按完成时刻。** 卡面时刻取卡面成片的 `finished_at`，列表排序、游标、`since` / `until` 都作用在它上面。这是资料库自己的规则，与全站列表按建立时间排不同。
5. **卡的 id 是对话 id**；不挂对话的出片，卡 id 是出片 id。对话 id 因此对持 `generation:read` 的人可见，读对话仍按对话自己的权限；「能否打开这段对话」另给字段表达。
6. **卡的作者是对话属主**；`userName` 筛选与 `/library/authors` 按属主数卡。不挂对话的卡，作者是出片属主。
7. **资料库不看删除标记。** 卡所在的对话删了、祖先删了，卡都照旧。
8. `root_job_id` 只剩血缘与无镜号分组两个用途。审计不变：副本整体不计。`GenerationOut` 不加 `conversationId`。

## 取舍

- **接受**：同一条成片出现在祖先的卡和每个有自己成片的副本的卡里，不合并、不去重。
- **接受**：继承规则在资料库 SQL 里再写一份（模块边界不让复用对话仓储与生成模块的实现）；用同一套分叉测试场景钉住两份，漂了会现形。
- **接受**：已删对话的成片全站仍可见，属主自己反而打不开那段对话，治理者能打开。
- **接受**：对话 id 对全站可见。
- **接受**：资料库按完成时刻，与全站列表口径不同；先提交、后完成的片版本号靠后，在列表里也靠前。
- **不做**：继承标注与 `GenerationOut.conversationId`。分镜页与资料库都不区分继承行。
- **不做**：只装自己的行。卡与分镜页对不上，V1/V2 两边不一致。
- **不做**：像审计那样剔掉副本。副本的成果进不了资料库；审计剔副本是怕重复计数，画廊不数数。
- **不做**：整条血缘并进源对话一张卡。副本做的合成会跑进源对话的卡。
- **不做**：一分叉就建卡。会立刻多一张一模一样的卡，分叉多半是为了试验。
- **不做**：卡 id 用不透明代号。多一层映射，只为藏一个不给权限的 id。
