# ADR-0008：常驻类型登记了灰着的原因才在选择页列空行

- 状态：已接受（2026-10-07）
- 取代 ADR-0006 第 2 条中「常驻项还没有产物时选择页照样列一行灰的」一句；常驻项的其余规则不变。
- 影响：前端工作台注册表 [artifact.ts](../../web/src/shared/workbench/artifact.ts) 的 `empty`，选择页 [workbench-host.tsx](../../web/src/shared/workbench/workbench-host.tsx)，登记 [workbench-registry.ts](../../web/src/app/workbench-registry.ts)。

## 背景

制作页按确切路径 `film.icml` 认领，按 ADR-0006 是常驻项，于是每段对话的选择页都多一行灰的「制作」。工程文件只有 AI 导演交付，别的 agent 的对话里这一行永远不会亮，只会让人以为少做了什么。比较过的方案：照旧列灰行，当作给 AI 导演的提示；按对话用的 agent 决定列哪些类型；登记时声明没有产物要不要列。

## 决策

常驻类型登记了 `empty`（灰着的原因）才在还没有产物时列一行灰的；没登记的等有了产物再出现。有了产物以后与其他常驻类型一样占标签位、按路径认领。只有某个 agent 才交付的类型不登记 `empty`，现在是制作页。

## 取舍

- **接受**：AI 导演的对话在写出工程文件之前，选择页上看不到「制作」。
- **不做**：按 agent 决定选择页列哪些类型。注册表不知道对话用的是哪个 agent，要为一行提示把 agent 信息传进工作台，不值得。
