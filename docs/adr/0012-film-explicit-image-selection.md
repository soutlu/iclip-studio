# ADR-0012：生图节点只认明确选用，生成不自动用上，缺图只提醒不拦

- 状态：已接受（2026-10-07）
- 不取代已有 ADR；沿用 ADR-0007 第 3 条（生成结果不进两个文件，运行文件写明某个生图节点用登记的哪一张）。
- 影响：[CONTEXT.md](../CONTEXT.md) 的「工程文件」「制作页」词条、[architecture.md](../architecture.md) 的 `iclip_studio` 说明、[contract/conventions.md](../../contract/conventions.md) §6 的制作页；后端 [film.py](../../server/src/iclip/capabilities/iclip_studio/film/film.py) 的取图、[conversation_film.py](../../server/src/iclip/app/conversation_film.py) 的生图、[studio.py](../../server/src/iclip/capabilities/iclip_studio/film/studio.py) 的制作页视图；前端制作页的生成卡 [film-generate-card.tsx](../../web/src/features/storyboard/film/film-generate-card.tsx) 与图片编辑器 [image-edit/](../../web/src/features/storyboard/image-edit/)。

## 背景

一个生图节点用哪张图原来分三档：运行文件里选用的；没选用就用它最近一次按描述生成成功的；都没有就没图。于是生成成功会自动用上，而已经有图的再生成会把现在这张顶掉，后端只好在再生成前先把现在这张写进运行文件选用。用户分不清舞台上那张是选的还是刚生成的，取消选用也会落回某一次生成，而不是空白；生成出来的图有时不满意，却已经被出片用上。

比较过的方案：保留三档，只在再生成前先选用现在这张（原来的做法）；保留三档，再生成的结果也自动替换；只认运行文件里明确的选用。缺图时：拦住生成与出片；自动先生成缺的图；只提醒、照常只用文字。

## 决策

1. **只认明确选用。** 生图节点在用的图只看运行文件里的 `use`；没有选用就是没有图，生成过、编辑过都不算。用户给的照片（工程文件里 `media:Image` 的 `src`）照旧总有图。
2. **生成从不写选用。** 按描述生成成功只多一个版本；用户在生成卡或图片编辑器里点「选用这张」，才把这张登记进运行文件并写 `use`。
3. **取消选用即空白。** `PUT .../film/image` 的 `url: null` 删掉这张图的 `use`，它就没有图，不回退到任何一版。
4. **缺图只提醒不拦。** 生成一张图、或给一组出片时，它挂的生成图里有没图的，照「有图用图，没图只用文字」照常发出；页面在按钮附近写一行哪几张缺、只用描述，不拦、不弹窗。生图那一张缺哪几张由视图的 `missing` 给出，出片那一组由 `frames` 里没图的生成图推出。

## 取舍

- **接受**：生成完要多点一次「选用这张」才用上；还没选用的生成图在舞台上仍是生成卡，卡上放那次结果的预览与选用按钮。
- **接受**：编辑器要能开在没有在用的图上：版本条没有「在用」一格，选中一版点「选用这张」，撤销回到空白。
- **接受**：开发环境里靠「最近一次生成」用上的图，改后在制作页上显示为没图，要重新选用；这套功能没进过发布版本，不迁移。
- **不做**：再生成前先选用现在这张。生成不写运行文件，现在这张本来就在运行文件里，或本来就没图。
- **不做**：缺图时拦住生成或出片，或自动先生成缺的图。生成要花钱，生不生成由用户决定；只用文字也能出结果。
