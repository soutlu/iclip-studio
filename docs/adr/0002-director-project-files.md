# ADR-0002：AI 导演工程文件显式声明发给模型的全部内容

- **状态**：已接受（2026-10-09）
- **影响范围**：[CONTEXT.md](../CONTEXT.md)「导演工程文件与制作页」；[contract/conventions.md](../../contract/conventions.md) §6；AI 导演写作指南 `film-guide.md`

## 背景

在短片制作流程中，AI 导演和用户都会在制作页上修改分镜设定与参考图。为了保证「所见即所得」，工程文件本身应当直接、完整地表达最终发给生图和视频大模型的全部内容，而不是在后端提交时隐式拼接或猜测。

## 决策

1. **双文件职责分离**：每个导演工程由两个工作区文件组成——内容文件 `film.icml` 负责定义设定、剧本和生成请求；运行文件 `film.icrun` 负责登记候选图片地址，并通过 `use` 语句指明每个节点当前选用了哪张图片。生成的图片结果只写进 `film.icrun`，不回写 `film.icml`。
2. **专用标记语言**：采用自研的 ICML 标记语言与解析器。
3. **显式参考图列表与 `@ImageN` 编号**：每个生图节点和视频节点下都挂有一份有序的参考图列表。AI 导演在节点专属文本中直接写 `@Image1..N` 引用列表对应位置的图片；带 `@ImageN` 编号的文字只能给单个节点独占使用，不带编号的纯文本设定可以跨节点共用。
4. **缺图拦截**：节点参考图列表中的每一项都必须已选用实际图片；只要有任何一项缺图，系统直接禁止生成该图片或该组视频。
5. **镜头机位图的选用联动**：每个镜头的专属机位图声明在镜头的 `view` 属性上。当用户在页面上选用某张机位图时，系统会将其追加进该组视频的参考图列表，并在对应镜头正文开头插入 `参考@ImageN，`；取消选用时同步移除这两处内容并重排后续图号。
6. **制作页修改直接写回工程文件**：用户在制作页上修改文字、增删或更换参考图、选用机位图、调整画幅，全部在校验通过后同步写回工程文件；后端在向大模型提交生成请求时原样发送文件内容，不再额外补充编号或引用句。
7. **统一提示词模板與剧本引用**：生图提示词套用 `picture-v1` 模板，视频提示词套用 `multi-shot-video-v1` 模板；台词统一写在 `<script>` 剧本块中（一句一段），镜头正文通过 `{段名}` 引用台词。
8. **保存即校验**：`film.icml` 与 `film.icrun` 在保存时均须通过语法与结构检查，不合法则拒绝写入。

## 取舍

- **接受**：选用或取消选用机位图会直接改动 `film.icml` 原文及后续参考图的 `@ImageN` 编号；旧版格式工程文件不再兼容，需由 AI 导演按新规范重写。
- **不做**：不在缺图时用文字描述顶替图片；不在后端提交模型时隐式修补图号或引用前缀。
