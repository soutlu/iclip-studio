# ADR-0007：AI 导演的工程文件用自己的标记语言，写法照 hypit，运行时自己实现

- 状态：已接受（2026-10-06）
- 不取代已有 ADR。
- 影响：[CONTEXT.md](../CONTEXT.md) 的「工程文件」词条、[architecture.md](../architecture.md) 的 `iclip_studio` 说明、[contract/conventions.md](../../contract/conventions.md) 的工作区文件写回；后端运行时 [iclip_studio/film/](../../server/src/iclip/capabilities/iclip_studio/film/)。

## 背景

AI 导演照参考片做新片：Brief、参考片拆解、新片执行方案之后，要有一份能执行的制作文件，记下这条片要生成的每张图和每次视频请求。原来由 agent 直接交付分镜文件 `video_shot.json`，它只装得下一次出片请求：出场元素要在每张图里重写，参考图的生成参数、台词脚本没有地方放。

开源工具 hypit 用一份标记文件描述整条片，写法简单：文件头选写法，`import` 引入包，普通值加引号，引用写花括号，先定义后引用，一个模型一个包。它的许可证第 1a 条不允许用它的源码或衍生作品运营多租户服务，本产品是多租户的。比较过的方案：直接用 hypit 的运行时；继续只写 `video_shot.json`；自己定义文件。

## 决策

1. **文件是自己的，写法照 hypit。** 工程文件叫 `film.icml`，运行文件叫 `film.icrun`，文件头与根标签用同样的两个词；`svml` 是 hypit 自己起的名字，不沿用。读文件、检查、拼提示词用 Python 自己实现，不用 hypit 的代码。标签与属性以包声明为准，文件里没有 `import` 的包不认识。
2. **出场元素定义一次，到处引用。** 人物、产品、场景各写一个 `Element`；图片和视频的提示词用 `Cast` 引用它，有图就带上图，没图只用文字。图的编号不写在文件里，由后端按当下有图的现算：参考图和机位图都由用户决定生不生成，写文件时不知道最后有哪些图。
3. **生成结果不进这两个文件。** 每次生成本来就在生成任务表里记一行。运行文件只做两件事：登记现成的图片地址并起名，写明某个生图节点用登记的哪一张。认图片用地址，不用任务号：人也要改这个文件，地址可以复制粘贴。
4. **没有模板，也没有档位。** 图片提示词是拍摄、主体、取景、环境四段话，视频提示词是全局设定加逐镜时间线；拼法由 `Picture` 与 `Storyboard` 两个标签各自规定，写在代码里，不加任何固定的话。
5. **长片在文件里拆。** 一个 `Storyboard` 是一次视频请求，镜头时间从 0 起；超过模型时长上限时在工程文件里拆成几个，导出时原样照搬，不换算时间。
6. **单向导出分镜。** `export_shots` 把每个视频节点导出成 `video_shot.json` 的一个镜头组，并带上模型名；分镜页只读这份文件，不需要知道它是导出的，页面上的修改不写回工程文件。
7. **agent 不选模型。** 生图固定 GPT Image 2.5、分辨率只开放 2k，视频固定 Seedance 2.5；模型名仍写在文件里，换模型只换一个包。
8. **人和 agent 都能改这两个文件，工具不改。** agent 每次改完自己调用 `check_film`；人写回时后端用同一套规则校验被写的那一个文件。

## 取舍

- **接受**：运行文件的标签名与 hypit 不同（`film`、`media:Image`、`use`），懂 hypit 的人要对照一次。
- **接受**：`.icml` 与 Adobe InCopy 的文件后缀同名；这两个文件只在工作区里使用。
- **接受**：人写回时只校验被写的那一个文件，要对照另一个文件或对话素材的规则留给工具；写回校验的入口只拿得到这一份内容。
- **不做**：用 hypit 的运行时。许可证不允许，理由见背景。
- **不做**：把生成结果或「用第几条」写进工程文件。工程文件只描述怎么做，不随生成进度变。
- **不做**：模板文件与档位。现在没有要固定下来的话；以后有了，再照 hypit 加模板文件和一个可选的模板属性，不写这个属性的旧文件照现在的规则拼。
- **不做**：导出时把全片时间换算成每次请求里的时间。镜头正文里写的秒数没法跟着换算。
- **不做**：agent 写文件时自动检查。agent 分几步改一个文件，中间的状态本来就过不了检查。
- **不做**：分镜页向工程文件反向同步，以及 1k、4k 分辨率。
