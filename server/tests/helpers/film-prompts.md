# 拼出来的完整提示词（新设计草稿，按下面的规则手写的预期结果，没有代码跑过）

## 拼接规则

1. 图片编号：每次生成时按这个生成节点列出的参考图先后编号，只给已经有的图编号，没有的跳过。生图和视频都写成 `@ImageN`。视频的机位图接在列出的参考图后面编号，同一张图只编一个号。
2. 元素的图：生图里写在这个元素的文字后面——「参考@ImageN」，几张用「、」连起来。元素后面紧跟着追加的文字（人物的身材句）算这个元素的，图号写在它后面。前面的文字已经以句号结尾时直接写「参考@ImageN」，否则先加「，」，以「。」结尾。视频元素行有图时冒号后不写元素的文字，只写模板里这个槽的几个字加「参考@ImageN」：人物「长相、发型和穿着」，产品「外观」，场景「环境」；几张用「、」连起来，不加句号。没有图就不写。
3. 另挂的图：用途句后面加「，参考@ImageN。」，放在生图「场景」段末尾。没有图这一句整句不写。用途句不写「它」，直接说参考的是什么。
4. 视频镜头：有机位图时镜头开头写「参考@ImageN，」；没有就不写。
5. 空的槽：段名和内容都不写。段与段之间空一行；段名单独一行。
6. 一张参考图都没有：生图走文生图，视频不带参考图。
7. 生图里元素文字始终写全，有没有图都一样；视频里只有还没有图的元素写全文字。
8. 每镜前面的「[起–止秒｜镜头N]」和最后一行「不要生成字幕，不要生成背景音乐。」由出片的后端加（与现在相同）。
