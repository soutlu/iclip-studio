Extended colors

领域扩展色分两类：随主题——引用语义角色的自动跟随，直接取色阶或字面值的在 .dark 另给值；主题中立——内容身份色、纸面材质、媒体遮罩，明暗不变。新增扩展色先向 primary 做色相调和。

核心状态契约

状态层 = on-surface 以 --state-* 透明度叠在底色上；组件不自写 hover / pressed / disabled 颜色。

Hover --state-hover · 8% 前景色状态层；按钮另加放大 1.05。工具类 ui-state。
Pressed --state-pressed · 12% 按压状态层；按钮另加缩小 0.95。
Focus visible --state-focus-ring · 3px / --state-focus-offset · 2px 描边 --color-focus-ring；只响应键盘。工具类 ui-focus。
Selected --color-state-active 底 primary-container、字 on-primary-container；以 aria-pressed / aria-selected 暴露。
Dragged --state-dragged · 16% 状态层 + shadow-2。
Disabled content 38% · container 12% ui-state 压暗文字与描边、撤销叠层、cursor not-allowed；实心容器另加 disabled:bg-disabled-container。
Loading spinner icon-md · aria-busy 保持原控件尺寸、阻止重复触发。
Invalid error ring + helper 描边与辅助文字 error，不改底色；aria-invalid 并关联错误说明。
Transition --dur-s · --ease 状态变化 150ms 标准曲线。工具类 ui-motion-s。

Iconography

通用 UI 图标由 @/shared/icons 的类型化注册表管理；本页只保留使用契约，不展示图形目录、不嵌入 SVG。

Source Lucide 为唯一通用图标来源，每个语义名称绑定一个 Lucide 组件，不做运行时 fallback。键名按用途起（search close run），不按图形起。
Scale --icon-xs — xl · 12 / 14 / 16 / 20 / 24px；描边 2。按钮内与菜单项 icon-md，图标按钮与输入框内 icon-lg，Chip / Tag icon-sm，角标 icon-xs，空态 icon-xl。
Color 使用 currentColor；默认、危险、选中和 disabled 颜色由父级语义控件统一接管。
Hit area Icon-only control 使用 IconButton 外壳（lg 40 / 48、md 36 / 44）并提供 aria-label；SVG 不承担命中区。
Accessibility 装饰性图标 aria-hidden；单独承载含义的图标必须传 label，缺失时组件抛错，不静默降级。
Runtime bridge @/shared/icons 只公开 Icon 与 IconName；组件使用语义名称，不直接导入 lucide-react（ESLint 拦截）。改名或删除一次迁完全部调用点，不留兼容别名。
Scope 通用 UI 图标进入注册表；品牌图形与插画（如 HippoIcon）放 shared/ui/icons；标注、编辑器引用等业务专用图形由所属 feature 管理；图表与动态几何不进入图标系统。

Usage

收敛原则

判断一项内容是否应该进入设计系统的三条规则。

Token 优先

颜色只引用语义角色与领域别名，排版和尺度只引用已命名 token；没有则先加入本页再镜像运行时，不在业务页面写第二套数值。

模板只管结构

模板拥有布局、槽位、响应式节奏和滚动关系；数据、权限、路由与交互逻辑由业务层提供。

两处复用再上收

只有在两个独立 feature 中重复出现的稳定组件或结构，才进入契约表与 shared/ui；单一业务样式保持局部。
