Design System

iClip 全站视觉语言的单一事实源。上方第一个 <style> 定义全部基础 Token，运行时由 web/src/app/globals.css 与 base.css 镜像并通过 pnpm lint:design 双向对账。界面保持纯中性克制，将视觉重心留给影像作品本身。

颜色与材质守则

颜色只用于承载语义与引导视觉层级
  • 表面纯中性，画面做主角 页面、侧栏、卡片与表单只使用唯一 Neutral 灰阶，避免界面色偏干扰审片与调色判断；层次靠浮起卡片（--color-card）、凹陷槽（--color-control-well）与发丝线建立。
  • 三层主动作纪律 品牌绿 primary 全页仅留给唯一核心交付（如「生成」「导出」）、正文链接与运行/成功态；高优确认动作统一用 action-neutral 墨色实心；常规操作使用描边或透明态。
  • 分类与媒体语义色（tone-*） 凡落在 UI 表面的时间线波形、工作台双色图标、片段标签与图表分组，统一消费明暗成对的 5 槽 --color-tone-*（slate / teal / umber / copper / ochre），在卡片与凹陷槽底色上均满足 WCAG AA；主要用于线条、波形与双色图标内填充，不做大面积浅色铺底，小尺寸实底徽标统一配纯中性 --color-on-tone；禁止为单一新页面另造私有色表。
  • 镜头点缀色（accent-1…8） 仅用于按镜头序号循环标识身份（时间轴色段与镜头序号旁短色签同色），面积小且固定；序号文字仍保持中性色，不铺浅色底块，不用于导航、按钮或状态。
  • 焦点与选中态 键盘焦点仅在 :focus-visible 显露，统一使用 2px --color-focus-ring（即 on-surface）；输入框聚焦时 1px 边框转墨色；深色媒体面改用 on-scrim。选中与拖放目标采用中性态，不使用绿色光环或浅绿铺底。
  • 图标着色边界 通用操作与配置资源图标使用单色 on-surface（24px 网格）；复杂创作工作台（如 final-cut 编辑器）的媒体导航与轨道头允许以双色（Duotone）内填充绑定 --color-tone-*，描边仍保持克制。
  • 状态色 警告与吸附提示用 tertiary 琥珀（warning 为其别名），错误与不可逆危险操作用 error 红；运行中与成功共用品牌绿。
  • 契约准入原则 全局 design-system.html 只收编跨模块复用的通用语义；单页特化纸面或独立实验浮窗留在模块局部样式，不污染全局契约。

04 · Interaction & Copy

交互体验与界面文字规范

统一的交互习惯与克制的书面语口径，确保多模块协作时体感一致，不向用户暴露工程内部实现。

  • 通用操作用图标，领域概念配短词 播放、静音、撤销、删除、关闭、全屏等高频通用动作可只用清晰图标配即时悬停提示；涉及业务概念与 AI 能力的入口（如「镜头」「贴片」「生成音乐」「对齐口型」）必须配 2–4 字中文短词，不让用户猜图标。
  • 键盘、触屏与加载防抖 所有核心交互同时支持鼠标、键盘与触屏：悬停才露出的控件需以 touch: 在触屏设备常驻；加载态按钮保持原尺寸不跳动，并阻止重复提交；弹窗打开后接管焦点，关闭后归还焦点。
  • 不暴露底层内部标识 界面统一使用中文（固定功能名 final-cut 除外，与中文相邻两侧各留一个空格）；严禁向用户展示原始工具函数名、内部 ID、文件路径或 JSON 字段。
  • 书面语与标点口径（单一事实源） 保持冷静、直接、可执行的书面语，不使用感叹号、颜文字或空泛安抚；数量与限制写具体数字，引用界面按钮原名用直角引号「」；单句提示末尾不加句号，原因与操作建议之间用分号隔开。六类提示标准句式详见 前端实现规范 · 界面文字 与 ADR-0001。
