# 首页登录弹窗与按页守卫

## 决策

未登录用户可以进入首页并看到应用壳；需要登录的动作通过 `useLoginPrompt()` 请求应用壳打开登录弹窗。账号密码登录成功后关闭弹窗，留在当前页面。

- 不建立独立登录页，也不在应用壳统一拦截未登录用户。
- 整页都需要登录的页面使用 `beforeLoad` 与 `ensureSessionUser()` 守卫；未登录时回首页，不添加 next 参数或自动打开弹窗。
- 登录弹窗由应用壳持有，feature 不自行创建。登录通道只有飞书 SSO 与账号密码，不加手机号验证码或协议勾选。
- SSO 使用整页跳转；回调失败时返回 `/?ssoError=<code>`，由应用壳展示登录错误。关闭弹窗时移除错误参数，避免刷新重复触发。
- 普通接口的 401 / 403 触发 `/users/me` 复核，再重算路由；不能仅凭单次接口失败认定用户已退出，也不自动弹窗。登录、登出、SSO 与会话探测中的预期 401 由认证流程处理。
- 登录状态变化后重算路由。退出登录后保持当前页；页面有登录守卫时，由守卫送回首页。原请求的错误仍由调用方展示。

## 取舍

首页保留游客入口，动作通过弹窗请求登录；私有页面通过路由守卫保护。该决策替代 [ADR-0001](0001-vite-spa-same-origin-no-bff.md) 中旧的登录路由处理，认证与同源代理决策保持不变。
