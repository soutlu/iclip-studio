# Sample font

`sample-font.otf` is a renamed test subset of Noto Sans CJK SC Regular, licensed under SIL OFL 1.1. The license is in `sample-font.LICENSE.txt`; embedded copyright and license metadata are preserved. The family and PostScript names were changed to Iclip Test Sans / IclipTestSans-Regular.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

Original SHA-256: `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`.

The subset includes printable ASCII and the Chinese characters used in the test fixtures. `sample-font-info.json` contains its actual character coverage and face metadata for the MSW font-info endpoint. This asset is only for tests and mock previews; production brand fonts are uploaded resources.
